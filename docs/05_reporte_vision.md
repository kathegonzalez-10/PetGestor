# 5. Reporte de visión

## Descripción general

PetGestor es un sistema desarrollado en Python para la gestión de Peticiones, Quejas, Reclamos y Sugerencias (PQRS) relacionadas con la atención de perros y gatos en la UdeA.
El sistema busca digitalizar y organizar el proceso de gestión de las PQRS, reemplazando el manejo manual de la información mediante documentos físicos. 
PetGestor permitirá registrar las solicitudes, almacenar la información correspondiente, consultar su estado y realizar seguimiento a las fechas límite de respuesta.
De esta manera, el sistema contribuirá a centralizar la información de las PQRS y facilitar su gestión mediante una herramienta informática estructurada.

## Objetivo general

Desarrollar un sistema en Python que permita gestionar de manera organizada las Peticiones, Quejas, Reclamos y Sugerencias (PQRS) relacionadas con la atención de perros y gatos.

## Objetivos específicos

- Registrar las PQRS y la información correspondiente a cada solicitante.
- Organizar la información de las PQRS mediante archivos de datos.
- Permitir la consulta y seguimiento del estado de las solicitudes.
- Controlar las fechas límite establecidas para la respuesta de las PQRS.
- Facilitar la generación de información para el análisis y seguimiento de las PQRS.

## Beneficios

- Organización y centralización de la información de las PQRS.
- Facilita el seguimiento de las solicitudes registradas.
- Permite controlar las fechas límite de respuesta.
- Reduce la dependencia del manejo de información en documentos físicos.
- Facilita la consulta de información para el seguimiento y análisis de las PQRS.
